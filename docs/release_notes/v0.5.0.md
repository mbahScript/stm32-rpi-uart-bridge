# Release Notes – v0.5.0

This release introduces Transport for London (TfL) API integration and background service automation for the Raspberry Pi gateway.

---

## Highlights

- Real-time TfL API integration
- Raspberry Pi background polling service
- Linux systemd service support
- STM32 firmware TfL summary handling
- periodic transport telemetry broadcast

---

## New Features

### TfL API Integration

The Raspberry Pi gateway retrieves real-time tube line status from the TfL Open Data API.

Example summary:
```
TUBE: Bakerloo=Good Service; Central=Minor Delays; Circle=Good Service
```

This summary is transmitted to the STM32 device using the UART transport protocol.

---

### Background Service

A Python service continuously polls the TfL API and updates the embedded node.

The service runs automatically using **systemd**.

---

### STM32 Firmware Updates

Firmware now supports:

- receiving TfL summary packets
- storing latest transport data
- broadcasting TfL updates periodically

Supported commands:
```md
PING
STATUS
SETROUTE
SETETA
TFL=<summary>
GETTFL
```

---

| Event | Interval |
|------|------|
